# 2D

## Coordinate system

- Origin top-left, **+Y is down**. "Up" is `Vector2.UP` = `(0, -1)`. Gravity is positive Y.
- Angles in radians, clockwise-positive on screen. `Vector2.RIGHT.rotated(rotation)` = facing direction for sprites drawn facing right.
- `position` is relative to the parent; `global_position` is world space. Canvas layers (`CanvasLayer`) have their own space — UI in a `CanvasLayer` doesn't move with `Camera2D`.

## Platformer controller (feel-complete baseline)

```gdscript
class_name Player
extends CharacterBody2D

signal died

@export_group("Run")
@export var max_speed: float = 180.0
@export var ground_accel: float = 1400.0
@export var ground_friction: float = 1800.0
@export var air_accel: float = 900.0

@export_group("Jump")
@export var jump_height: float = 56.0          # px
@export var time_to_apex: float = 0.36         # s
@export var fall_gravity_multiplier: float = 1.6
@export var jump_cut_multiplier: float = 0.45  # velocity kept when jump released early
@export var coyote_time: float = 0.1
@export var jump_buffer_time: float = 0.12
@export var max_fall_speed: float = 520.0

var _gravity: float
var _jump_velocity: float
var _coyote_left: float = 0.0
var _buffer_left: float = 0.0

@onready var _sprite: AnimatedSprite2D = %Sprite


func _ready() -> void:
	# Derive physics from designer-facing values: height and time are what players perceive.
	_gravity = 2.0 * jump_height / (time_to_apex * time_to_apex)
	_jump_velocity = -_gravity * time_to_apex


func _unhandled_input(event: InputEvent) -> void:
	if event.is_action_pressed(&"jump"):
		_buffer_left = jump_buffer_time
	elif event.is_action_released(&"jump") and velocity.y < 0.0:
		velocity.y *= jump_cut_multiplier


func _physics_process(delta: float) -> void:
	var on_floor := is_on_floor()
	_coyote_left = coyote_time if on_floor else maxf(_coyote_left - delta, 0.0)
	_buffer_left = maxf(_buffer_left - delta, 0.0)

	# Gravity: heavier on the way down for a less floaty arc.
	if not on_floor:
		var g := _gravity * (fall_gravity_multiplier if velocity.y > 0.0 else 1.0)
		velocity.y = minf(velocity.y + g * delta, max_fall_speed)

	# Jump: buffered press + coyote window.
	if _buffer_left > 0.0 and _coyote_left > 0.0:
		velocity.y = _jump_velocity
		_buffer_left = 0.0
		_coyote_left = 0.0

	# Horizontal: accelerate toward target speed (per second — move_and_slide applies delta).
	var axis := Input.get_axis(&"move_left", &"move_right")
	var target := axis * max_speed
	var rate: float
	if on_floor:
		rate = ground_accel if absf(axis) > 0.0 else ground_friction
	else:
		rate = air_accel
	velocity.x = move_toward(velocity.x, target, rate * delta)

	move_and_slide()
	_update_animation(axis)


func _update_animation(axis: float) -> void:
	if axis != 0.0:
		_sprite.flip_h = axis < 0.0
	if not is_on_floor():
		_sprite.play(&"jump" if velocity.y < 0.0 else &"fall")
	elif absf(velocity.x) > 5.0:
		_sprite.play(&"run")
	else:
		_sprite.play(&"idle")
```

Node tree:

```
Player (CharacterBody2D)  — player.gd
├── Sprite (AnimatedSprite2D, unique name)
└── Collision (CollisionShape2D, CapsuleShape2D)
```

Notes:
- Capsule shapes slide over tile seams better than rectangles.
- For one-way platforms: enable `one_way_collision` on the platform's CollisionShape2D; to drop through, briefly clear the player's mask bit for that layer (`set_collision_mask_value(PLATFORM_LAYER, false)` then restore on a short timer).
- Slopes: `floor_max_angle`, `floor_snap_length` (increase to stick to downward slopes), `floor_constant_speed`.
- Moving platforms: use `AnimatableBody2D`; `CharacterBody2D` inherits platform velocity automatically (`platform_on_leave` controls what happens on jump).

## Top-down controller

```gdscript
extends CharacterBody2D

@export var max_speed: float = 160.0
@export var accel: float = 1200.0
@export var friction: float = 1600.0

func _ready() -> void:
	motion_mode = CharacterBody2D.MOTION_MODE_FLOATING   # no floor/wall/ceiling semantics

func _physics_process(delta: float) -> void:
	var dir := Input.get_vector(&"move_left", &"move_right", &"move_up", &"move_down")
	var rate := accel if dir != Vector2.ZERO else friction
	velocity = velocity.move_toward(dir * max_speed, rate * delta)
	move_and_slide()
```

`Input.get_vector` already normalizes and applies a circular deadzone — don't normalize again (it would make analog sticks all-or-nothing).

## TileMapLayer (4.3+)

- One `TileMapLayer` node per layer (Ground, Walls, Decoration), all sharing one `TileSet` resource. `TileMap` is deprecated.
- Physics: add a physics layer to the TileSet, paint collision polygons per tile. Set that physics layer's collision layer/mask to your "world" bit.
- Custom data layers on the TileSet (`is_hazard`, `footstep_sound`) instead of checking tile atlas coordinates in code:
  ```gdscript
  var cell := ground.local_to_map(ground.to_local(global_position))
  var data := ground.get_cell_tile_data(cell)
  if data and data.get_custom_data(&"is_hazard"):
  	_die()
  ```
- Terrains (autotiling) for walls/ground; set peering bits once, then paint with the terrain tool.
- Scene tiles (tiles that instance a scene) for interactive objects placed by level designers — coins, spikes with scripts.
- Runtime changes: `set_cell()` / `erase_cell()`. Changes batch until end of frame; call `update_internals()` if you need physics to see them immediately.
- Large procedural maps: `set_cells_terrain_connect` is slow for huge areas; generate with `set_cell` and precomputed atlas coords.

## Camera2D

- One `Camera2D` as a child of the player is fine for simple games. For look-ahead, room-locking, or cutscenes, use a separate camera node that follows a target in `_physics_process` (with physics interpolation on) and owns its own logic.
- `position_smoothing_enabled` + `position_smoothing_speed` for basic smoothing; `limit_*` for level bounds (or set from the TileMapLayer's `get_used_rect()`).
- Screen shake: offset the camera with decaying noise, not random jumps each frame:
  ```gdscript
  @export var noise: FastNoiseLite
  var trauma: float = 0.0   # 0..1, add on hits

  func _process(delta: float) -> void:
  	trauma = maxf(trauma - delta * 1.5, 0.0)
  	var amount := trauma * trauma
  	var t := Time.get_ticks_msec() * 0.05
  	offset = Vector2(noise.get_noise_1d(t), noise.get_noise_1d(t + 100.0)) * 12.0 * amount
  ```
  Respect a "reduce screen shake" accessibility setting.

## Pixel art setup

Project Settings:
- `rendering/textures/canvas_textures/default_texture_filter` = **Nearest**.
- `display/window/size/viewport_width/height` = your base resolution (e.g. 320×180 or 640×360).
- `display/window/stretch/mode` = `viewport` (true low-res, everything snaps) or `canvas_items` (smooth UI text, sprites at native scale).
- `display/window/stretch/scale_mode` = `integer` to avoid uneven pixel sizes.
- `rendering/2d/snap/snap_2d_transforms_to_pixel` = on for crisp sprites (with `viewport` stretch mode); leave off if you want smooth sub-pixel camera motion with `canvas_items`.
- Camera jitter in pixel art is usually camera smoothing producing sub-pixel positions against snapped sprites — pick one strategy (snap everything, or smooth-camera with a high-res viewport).

## Draw order

- Sibling order = draw order (later on top). `z_index` overrides across the tree; keep it to a few documented values.
- Top-down depth: enable `y_sort_enabled` on the parent (and on TileMapLayers that contain tall objects). Sprite origins must be at the feet.
- UI always on a `CanvasLayer` (layer ≥ 1) so it ignores the camera.

## Parallax2D (4.3+)

`Parallax2D` nodes with `scroll_scale` (e.g. `(0.2, 0.2)` far background, `(0.6, 0.6)` mid) and `repeat_size` for infinite tiling. Replaces `ParallaxBackground`/`ParallaxLayer`. Don't put gameplay collision inside parallax layers.

## 2D lighting

- `PointLight2D` with a texture + `LightOccluder2D` for shadows; `DirectionalLight2D` for global light; `CanvasModulate` to darken the scene.
- Normal maps via `CanvasTexture` for lit sprites.
- Lights are per-pixel costs: dozens of shadowed lights on mobile will hurt. Bake the look into sprites where possible.
